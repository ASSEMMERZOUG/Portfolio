About

An engineer who thinks like an attacker.

I'm Assem Merzoug — an electrical engineer who found his way into web security and never looked back. Web application and API testing is what I do: breaking apps the way a real attacker would, then documenting exactly how I did it so the gap can be closed.

I test manually, not just with a scanner. Scanners find the obvious stuff; the bugs that cost real money — broken access control, business-logic flaws, an IDOR that leaks someone else's account — take a human who understands how the application is supposed to work.

Security is understanding how things break. Every bug is a lesson; every exploit is knowledge.

I publish my work under the handle 4ss3m. My learning path, including everything I'm studying next, is public on my roadmap.
